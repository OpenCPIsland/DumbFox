# End of Development of DumbFox
DumbFox, our unfinished server that has been powering OpenCPIPS for several months until now, is <strong>ceasing development.</strong> It is not the decision we wanted to take, but unfortunately several issues over the project has risen over the past months, including the departure of DumbFox's original author who knew most of the code.

<strong>We suggest using SmartFoxServer 2X/3 or another server software if needed.</strong>
